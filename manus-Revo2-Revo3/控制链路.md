# MANUS → Revo2 控制链路

环境：Ubuntu 22.04 + ROS 2 Humble 合容器 `airbot-revo-humble`（镜像 `airbot-revo:humble`）。  
宿主机工程：`/home/ubuntu/airbot-revo-workspace/manus-Revo2-Revo3`。  
容器内工程挂载：`/home/dt/manus-Revo2-Revo3`。  
当前算法：`joint_thumb`（MANUS 关节角直接映射，不做 IK）。

## 链路

```text
MANUS 手套 + 接收器 (USB 3325)
  -> manus_ros2 / manus_data_publisher          # Integrated SDK，约 60 Hz
  -> /manus_glove_0  (Right)  /manus_glove_1 (Left)
  -> manus_revo2_retarget  (algorithm: joint_thumb)
  -> /revo2_<left|right>/revo2_pid_controller/target_joint_states   # JointState，rad
  -> revo2_driver / revo2_pid_controller        # 真机才需要
  -> Revo2 速度接口
```

映射（无 IK）：

```text
四指 Stretch      -> 对应近端关节
ThumbMCPSpread    -> thumb_metacarpal_joint
Thumb MCP/PIP/DIP -> thumb_proximal_joint
```

没有灵巧手时只跑前半段：手套数据进 ROS，retarget 往目标话题发命令。目标话题 Subscription 为 0 是正常的。

## 当前验证状态

已用两只真实 MetagloveProHaptics 手套验证通过前半段链路：

- MANUS 接收器：USB `3325:0049`，Dongle ID `0x7E465340`
- 右手：`0xC6142F4C`；左手：`0xDF470310`
- `/manus_glove_0`、`/manus_glove_1`：约 60 Hz ROS 消息
- `/revo2_right/revo2_pid_controller/target_joint_states`：约 100 Hz
- `/revo2_left/revo2_pid_controller/target_joint_states`：约 100 Hz
- 当前使用 `target-only`，不会向 Revo2 真机发送运动指令

MANUS SDK 必须以 root 访问 USB 设备。普通 `dt` 用户只能看到 Core 初始化，不能正常读取手套数据；Compose 已配置 `user: "0:0"`、`privileged: true` 并映射 `/dev`。

日志中的 `Calibration_left/right.mcal` 缺失是校准文件警告，目前不阻断手套消息和目标话题输出。

## 容器

```bash
cd /home/ubuntu/airbot-revo-workspace/manus-Revo2-Revo3
docker exec -it -u 0 airbot-revo-humble bash       # 已在运行可直接进入
docker inspect airbot-revo-humble                 # 查看挂载和权限
```

Compose 配置已包含 host network、host IPC、`privileged`、`/dev`、`/run/udev` 和工程目录挂载：

```bash
cd /home/ubuntu/airbot-revo-workspace/manus-Revo2-Revo3
docker compose up -d
```

`exit` 只退出 shell，不删容器。停止用 `docker compose stop`，删除容器才用 `docker compose down`。

每个新终端进容器后：

```bash
docker exec -it -u 0 airbot-revo-humble bash
source /opt/ros/humble/setup.bash
source /home/dt/manus-Revo2-Revo3/Revo-Retargeting-revo2_retargeting/install/setup.bash
```

USB 接收器排查（`lsusb` 能看到 `3325` 但 SDK 连不上）：

```bash
docker exec -it -u 0 airbot-revo-humble bash
# 宿主机或容器 root
lsusb | grep 3325
ls -l /dev/bus/usb/*/*
sudo chmod 666 /dev/bus/usb/00X/00Y    # 换成 MANUS 实际 bus/device
```

当前容器已验证设备节点为 `/dev/bus/usb/001/023`。推荐直接以 root 启动 pipeline，不要只给 `dt` 用户运行 `manus_data_publisher`。

## 真实手套 → 目标话题（已验证）

```bash
docker exec -it -u 0 airbot-revo-humble bash
cd /home/dt/manus-Revo2-Revo3/Revo-Retargeting-revo2_retargeting
source /opt/ros/humble/setup.bash
source install/setup.bash

# 必须在 root shell 中运行，以获得 USB 写权限
ros2 launch manus_revo2_retarget pipeline_launch.py \
  hand_mode:=both \
  launch_manus_publisher:=true \
  controller_backend:=ros2_control
```

只测一只手把 `hand_mode:=both` 改成 `right` 或 `left`。

看数据：

```bash
docker exec -it -u 0 airbot-revo-humble bash
ros2 topic list | grep -E 'manus|revo2'
ros2 topic hz /manus_glove_0
ros2 topic echo /manus_glove_0 --once
ros2 topic echo /revo2_right/revo2_pid_controller/target_joint_states --once
ros2 topic echo /revo2_left/revo2_pid_controller/target_joint_states --once
```

也可以从宿主机直接启动常驻 pipeline：

```bash
docker exec -d -u 0 airbot-revo-humble bash -lc \
  'source /opt/ros/humble/setup.bash && \
   source /home/dt/manus-Revo2-Revo3/Revo-Retargeting-revo2_retargeting/install/setup.bash && \
   exec ros2 launch manus_revo2_retarget pipeline_launch.py \
     hand_mode:=both launch_manus_publisher:=true controller_backend:=ros2_control'
```

停这次 launch：在 launch 终端 `Ctrl-C`，或：

```bash
docker exec -it -u 0 airbot-revo-humble bash
pkill -f 'pipeline_launch.py|manus_data_publisher|manus_revo2_retarget_node'
```

目前尚未启动 `revo2_driver`，因为 `/dev/revo2_hand_left`、`/dev/revo2_hand_right` 尚未配置，且 `/dev/ttyUSB0/1` 的 Modbus 探测没有响应。当前只验证到目标关节话题，未向机械手发送命令。

先配串口，再起驱动并切到 PID，然后复用上面的 pipeline（或用一键 launch）：

```bash
docker exec -it -u 0 airbot-revo-humble bash
cd /home/dt/manus-Revo2-Revo3/Revo-Retargeting-revo2_retargeting/src/brainco_drivers/revo2_driver/setup
bash bootstrap_revo2.sh
bash check_revo2_setup.sh

# 需要先编译 revo2_driver，并下载 BrainCo Stark SDK
cd /home/dt/manus-Revo2-Revo3/Revo-Retargeting-revo2_retargeting
bash src/brainco_drivers/revo2_driver/scripts/download_sdk.sh
source /opt/ros/humble/setup.bash
python3 -m colcon build --symlink-install --packages-select revo2_description revo2_driver
source install/setup.bash

ros2 launch manus_revo2_retarget real_hand_pipeline_launch.py \
  hand_mode:=right \
  controller_backend:=ros2_control \
  launch_plot:=false
```

理想 controller 状态：`revo2_pid_controller` active，`joint_forward_pos_controller` inactive。

## 备注

- 如果以普通用户运行 publisher，可能出现 `No compatible license found` 或只有 `Manus Core connected` 而没有手套数据；首先确认 USB 写权限，并用 root 运行。
- 当前真实设备日志已显示 Dongle license data、两只手套连接和约 100 Hz SDK 数据率。
- `python3-serial` 已加入 Dockerfile，用于 Revo2 串口探测。
- Revo3 是另一套 workspace（`Revo-Retargeting-revo3_retargeting`），走 MIT 命令，不是这条 `joint_thumb` 链路。
